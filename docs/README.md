# Kosha

Kosha — небольшой редактор для совместной работы с Python, SQL и обычным Text без подсветки. Участники редактируют один документ по короткой ссылке вида `/Q1W2E3`; код не исполняется.

Текущий статус — работающий технический прототип. Он позволяет проверить совместное редактирование, переподключение, хранение и потребление памяти перед постоянным размещением.

- [Сборка и размещение на своём сервере](deployment.md)
- [Использование, сохранение и ограничения](usage.md)
- [Автоматические проверки и измерение памяти](verification.md)

Все ресурсы интерфейса обслуживаются самим приложением. Для работы установленного сервера Node.js, npm и внешние CDN не нужны.
