# Kosha

Небольшой редактор для совместной работы с Python, SQL и обычным текстом по ссылке. Код не исполняется.

Работающий технический прототип: Go + ygo, CodeMirror, Yjs и SQLite. Интерфейс встроен в один серверный бинарник.

```sh
make deps
make build
cp .env.example .env
./bin/kosha
```

Откройте [локальный редактор](http://127.0.0.1:8080), скопируйте ссылку комнаты во вторую вкладку или браузер.

Порт и остальные параметры задаются в `.env` в корне проекта: например, `KOSHA_PORT=8090`. После изменения перезапустите сервер и откройте выбранный порт. Локальный `.env` не включается в Git.

Новые комнаты получают короткий адрес вида `/Q1W2E3`. В режиме Text подсветка отключена, скачивание — в `.txt`.

Неактивные комнаты хранятся 14 дней (`KOSHA_ROOM_TTL=336h`). Открытие ссылки продлевает срок; пока участники подключены, комната сохраняется. После последнего выхода начинается полный новый срок.

Инструкции по сборке, запуску и размещению: [документация](docs/README.md).
